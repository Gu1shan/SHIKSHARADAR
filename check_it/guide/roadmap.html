The procedure behind the project plan

This guide (and the underlying plan) was produced with a repeatable method — so the team can defend how the plan was made:

  1. Clarify scope: SIH learning-outcome assessment.
  2. Verify ecosystem claims from official sources only (UDISE+, DIKSHA, Saral, VSK, NDEAR, NIPUN, ASER, DPDP).
  3. Identify the gap: marks-based systems lack concept-level error-pattern intelligence.
  4. Design: mistake fingerprinting, evidence-first, confidence-scored, teacher-in-the-loop.
  5. Architect: 3 levels (MVP → SIH → production) so a beginner can build it in 8–12 weeks.
  6. De-risk: synthetic data, edge-case matrix, testing targets, honest SIH scorecard.
  7. Document everything; label verified vs assumed vs unknown.
Epistemics rule used throughout: every claim carries a status — verified (official source), assumed (reasonable but unverified), or unknown (flagged, never invented). Nothing was fabricated to fill a gap.
