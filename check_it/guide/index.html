Shiksha Radar

"Find the learning gap before it becomes a learning failure."

An AI-powered early learning-support & learning-gap detection platform for Indian schools. It reads answers — not just marks — to find which concepts students struggle with, why, and what might help, with every claim backed by evidence and confidence scores.

How to use this guide

  • Read sequentially for the full picture — start at Problem & Research.
  • Jump by role: judges and evaluators → SIH Evaluation & Demo; developers → Architecture, Algorithms, Roadmap; researchers → Problem & Research, Sources.
  • Every claim is labeled: verified (official source), assumed (reasonable but unverified), unknown (flagged, never invented).
  • This is a plan, not a prototype — the goal is a detailed, research-backed plan a first-semester CS student can build in 8–12 weeks.
Bottom line: every architectural choice in this project has a reason, a source, and a buildable first step. Start with the synthetic-data generator on Day 1.
