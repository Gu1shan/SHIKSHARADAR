Mistake Fingerprinting

Every student develops a pattern of errors across assessments. Shiksha Radar fingerprints that pattern — by concept and by error type — over time.

Traditional view

"Student scored 60% on Fractions"

Shiksha Radar view

"Fractions → 7 errors across 3 assessments (84% confidence)
 ├─ Denominator handling: 5 (recurring, ↑ trend)
 ├─ Simplification: 1 (isolated)
 └─ Addition: 1 (careless)
 → Equivalent-fractions review + 5 targeted problems"

Not a dashboard, not a chatbot, not a predictor

It is NOT

  • A marks dashboard or attendance tracker
  • A generic AI tutor or chatbot
  • A "who will fail" prediction engine
  • A replacement for the teacher

It IS

  • Concept-granular — which concept, which error type
  • Longitudinal — patterns across assessments
  • Evidence-cited — every claim shows counts + confidence
  • Decision-supporting — the teacher stays in charge
Core positioning: it reports "which concepts show repeated difficulty, the evidence, and what might help" — never "this child will fail."

The end-to-end loop

Student assessments
        ↓
Answers + scores + assessment history
        ↓
Mistake analysis → Concept mapping → Repeated error detection
        ↓
Learning-pattern analysis → Student learning profile
        ↓
Teacher dashboard → Evidence-based intervention recommendation
        ↓
Targeted practice → Reassessment → Measure improvement
The feedback loop is the product: Detect → Intervene → Reassess → Compare → "Gap closed" or "Persisted". Interventions only become active after teacher approval.

User personas — designed around real workflows

👩‍🏫 Priya — Grade 5 Teacher

Govt school, 40 students, multi-grade. Pain: no time to analyze papers, doesn't know which concept to reteach.

Value: upload CSV → 30 sec → "Fractions: 12/40 struggling with denominators" → ready-to-print practice sheets.

🧑‍💼 Rajesh — Block Resource Person

Supports 50 schools. Pain: needs systemic gaps for training planning.

Value: aggregate view — "denominator errors high in 35/50 schools → district workshop."

👧 Anita — Student (indirect)

Grade 5. Pain: generic "do more practice" homework.

Value: targeted 5-question worksheet on her specific gap; sees progress next test.

🏫 Principal / Admin

Reports to district on learning outcomes.

Value: auto-generated "Learning Gap Report" with evidence for SMC/SMDC meetings.

Principle: the system supports teachers, never replaces them. Every feature maps to a persona's real decision.
